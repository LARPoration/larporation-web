# v0.0.0 — Unreleased

The initial release candidate contains six information pages: Home, About, Projects, People, Join and Contact. No publication date has been recorded.

## Features

- Cornerstone branding, construction styling and Intern as a Service humour.
- Post-launch project roadmap and email contact links.
- Instagram, TikTok, LinkedIn and GitHub organisation links with locally hosted icons.
- Shared pixel cursor with an off switch and system fallbacks.
- Right-click contributor inspection for elements, sections and pages; ordinary clicks remain available for navigation. Explicit inspection mode supports click selection.
- Persistent Time Travel bar with version summaries, in-place region transitions, historical credits and missing-page states.

## Current limitations

- The timeline manifest is empty; no historical production versions are published.
- The Cloudflare Pages static export includes the integrated timeline. Earlier states require explicit release records; no separate archive service is used.
- There is no application backend, account system or analytics integration. Contact actions open an email client.
- Browser regression coverage uses Chromium; it is not a full cross-browser or accessibility audit.
